description: Summarize what belay recorded in this session
allowed-tools: Bash(belay report:*)
---

Run `belay report` and read its output.

Then give the user a short summary in plain sentences:

- what needs attention first (loops, denied edits, warnings);
- what belay did, and why;
- anything that looks wrong, which the user can note with `belay flag`.

Do not paste the whole report back. Quote only the lines that matter.
